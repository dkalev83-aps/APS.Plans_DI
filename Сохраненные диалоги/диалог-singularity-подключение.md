# Диалог: подключение singularity-app к агенту

**Дата:** 19 октября 2026

---

## Задача

Пользователь попросил подключить личный задачник **singularity-app** к агенту Битрикс24 Коворк/Код, следуя инструкции на `https://me.singularity-app.com/mcp/`.

---

## Шаг 1. Чтение инструкции

Инструкция находится в личном кабинете SingularityApp (`me.singularity-app.com/mcp`), доступ к которому требует авторизации. Пользователь авторизовался в браузере самостоятельно.

### Ключевые данные из инструкции

- **URL MCP-сервера:** `https://mcp.singularity-app.com/mcp`
- **JSON-конфигурация:**

```json
{
  "mcpServers": {
    "singularity": {
      "url": "https://mcp.singularity-app.com/mcp"
    }
  }
}
```

- **Доступные инструменты (toolsets):**
  - `tasks` — задачи
  - `projects` — проекты
  - `meta` — основные сущности
  - `habits` — привычки
  - `kanban` — канбан-доски
  - `tags` — теги
  - `system` — пакетные операции (Batch, по умолчанию отключён)

По умолчанию Batch (`system`) отключён — это безопаснее, так как ассистент выполняет изменения последовательно.

---

## Шаг 2. Добавление конфигурации

В файл `opencode.jsonc` (рабочая директория) добавлен MCP-сервер `singularity`:

```jsonc
"singularity": {
  "type": "remote",
  "url": "https://mcp.singularity-app.com/mcp?toolsets=tasks,projects,meta,habits,kanban,tags"
}
```

**Выбранный набор инструментов:** все, кроме Batch (tasks, projects, meta, habits, kanban, tags).

---

## Шаг 3. Проверка валидности JSON

Конфигурация проверена — JSON валиден. Все 7 MCP-серверов на месте:

- `openwork-browser`
- `chrome`
- `bitrix24`
- `attachments`
- `memory`
- `openwork-ui`
- `singularity` (новый)

## Шаг 4. OAuth-авторизация

После перезапуска агента сервер singularity имел статус `needs_auth`. Авторизация выполнена через команду:

```bash
opencode mcp auth singularity
```

Результат: **Authentication successful!**

Проверка статуса (`opencode mcp list`): сервер singularity — **✓ connected**.

Debug (`opencode mcp debug singularity`):
- Auth status: ✓ authenticated
- Access token: есть
- Refresh token: present
- Connection successful

## Шаг 6. Вопрос про агента Гермес

Пользователь спросил, доступно ли подключение singularity для агента **Гермес**.

**Уточнение:** агент Гермес — это агент на платформе **VibeCode** (`https://vibecode.bitrix24.tech/agents`), а не локальный агент opencode.

### Ответ

**Для агента Гермес на платформе VibeCode подключение к singularity нужно настраивать отдельно.**

Причины:
1. Настроенное подключение относится только к локальному агенту Битрикс24 Коворк/Код (opencode в рабочей директории).
2. Агент Гермес работает на облачной платформе VibeCode с собственной изолированной конфигурацией.
3. MCP-подключения для облачных агентов VibeCode настраиваются в интерфейсе платформы.
4. OAuth-токен singularity хранится локально и не доступен облачному агенту — Гермесу нужна своя авторизация.

### Что нужно сделать для Гермеса

1. Зайти в настройки агента Гермес на платформе VibeCode.
2. Добавить MCP-сервер с URL: `https://mcp.singularity-app.com/mcp?toolsets=tasks,projects,meta,habits,kanban,tags`
3. Пройти OAuth-авторизацию singularity в браузере.

Пользователь выбрал вариант «Помоги настроить в интерфейсе». Платформа VibeCode требует входа в аккаунт Bitrix24 (открылась страница OAuth-авторизации).
